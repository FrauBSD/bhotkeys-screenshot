# Changelog

Newest first. Each section is a git tag; the bullets are what landed
in that tag (from the previous tag, or from the start of the
repository for 1.0).

## 1.1 (2026-10-04)

- man pages for `desktop-screenshot` and `window-screenshot`;
  `greeter-screenshot` is the same page as `desktop-screenshot`

## 1.0 (2026-10-03)

- `shot-desktop`: Print runs desktop-screenshot --feedback;
  Ctrl+Print under GNOME, KDE, MATE, and Xfce
- `shot-window`: Alt+Print runs window-screenshot --feedback;
  Ctrl+Alt+Print under GNOME, MATE, and Xfce
- `shot-greeter`: Print at the greeter runs greeter-screenshot
  --feedback
